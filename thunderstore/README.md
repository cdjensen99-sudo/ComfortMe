# ComfortMe

Hammer helper that highlights pieces which would raise the comfort of the room you are standing in.

Open the hammer grid: **This room: N** on the right, green **+N** chips on upgrades, and a group list when you hover a comfort piece (red / grey / green vs this room).

Does not change comfort values or recipes. Not a clone of Hygge or GetComfortable.

## Requirements

- BepInEx Pack for Valheim
